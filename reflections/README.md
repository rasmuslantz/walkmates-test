# Lab reflections

This directory is optional. You may write reflections in Word or another tool and export them
to PDF for Canvas. Reflections do not need to be public or committed to Git, and no duplicate
Markdown copy is required. Use the questions in
[`reflection-template.md`](../lab-instructions/reflection-template.md).

If you prefer Markdown, copy the template into this directory and optionally name the files:

- `lab1-reflection.md`
- `lab2-reflection.md`
- `lab3-reflection.md`
- `lab4-reflection.md`

Keep the original template unchanged so both partners can reuse the same structure throughout
the course.
